### 🛡️ About Me

I am **Maduabuna Josiah** ([@King-Jboy](https://github.com/King-Jboy)), a 200-level Cybersecurity student based in Nigeria 🇳🇬 with an unwavering drive to become a world-class **Ethical Hacker** and security researcher. 

I live in the Linux terminal, dissecting systems, understanding network protocols, and analyzing vulnerabilities from first principles. Alongside cybersecurity, I actively harness cutting-edge **AI tooling and LLM agent ecosystems** (Claude Code, Antigravity CLI/IDE, DeepSeek harnesses, Hermes) to multiply engineering velocity and build smarter defensive workflows.

- 🔭 **Current Focus:** Deep-diving into Penetration Testing labs, network exploitation, and privilege escalation mechanics.
- 🐧 **OS & Systems:** Advanced Linux practitioner across Debian, Arch, Ubuntu, and security distributions (Kali Linux).
- 🤖 **AI & Agents:** Exploring autonomous agent harnesses, prompt architecture, and LLM-assisted security research.
- 🌐 **Portfolio & Hub:** Check out my digital home at [kingjboy.tech](https://kingjboy.tech).
- ⚡ **Philosophy:** Continuous growth, discipline over procrastination, and excellence through faith.
