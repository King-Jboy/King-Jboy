I am **Maduabuna Josiah**, a 200-level Cybersecurity undergraduate based in Nigeria 🇳🇬 on an aggressive pursuit of mastery in **Ethical Hacking**, offensive security, and system defense.

I spend my hours in the Linux shell exploring network protocols, analyzing vulnerabilities, dissecting binaries, and running security labs. Beyond traditional cybersecurity, I am deeply invested in **agentic AI engineering** — leveraging LLM harnesses (Claude Code, Google Antigravity IDE/CLI/2.0, DeepSeek harnesses, and Hermes) to build automated analysis workflows, accelerate bug hunting, and enhance problem-solving.

- 🤖 **AI Agent Workflows:** Utilizing autonomous agent loops, prompt harnesses, and multi-model routing for security research and software development.
